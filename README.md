# Quiz — Mapa de la Reconquista

Site estático em HTML, CSS e JavaScript, em espanhol. Abra `index.html` ou publique a pasta inteira. Caminhos relativos permitem uso na Hostinger e no GitHub Pages, inclusive dentro de um subdiretório.

## Conteúdo e funcionamento

- 7 perguntas com 4 alternativas e seleção única.
- 28 comentários próprios, um por alternativa.
- Avanço bloqueado até selecionar uma resposta; voltar preserva a seleção.
- 4 perfis orientativos e resumo das respostas individuais.
- Oferta completa antes do pagamento, baseada no pacote fornecido pelo usuário.
- Checkout Hotmart indicado pelo usuário.
- Preço da página original: US$ 5,90, pagamento único.
- Nenhuma garantia de reembolso foi acrescentada: o material enviado não informa essa condição.
- Sem coleta ou envio de respostas. Elas ficam apenas na memória da página e se apagam ao recarregar.

## Publicação no GitHub Pages

Envie estes arquivos para o repositório escolhido. Em Settings → Pages, selecione publicação pela branch e a pasta raiz. Em repositório privado, a disponibilidade depende do plano da conta. Confirme preço, moeda e condições no checkout antes de usar em anúncios.

Para ajustar o checkout, edite o link com `id="checkout"` em `index.html`. Perguntas, comentários e perfis estão em `quiz.js`.

Os textos e imagens da oferta foram extraídos de `mapa-reconquista-mobile-hostinger 2.0.zip`. Não foram incorporados scripts de depuração do pacote original.
